# 松林卫士 · Pine Grove Guardian

一片松林被**松树线虫病**侵染，线虫肆虐，松树枯黄。主角在向导的指引下找到了**益生菌**与**无人机**，利用无人机释放益生菌净化线虫，并最终击败传播线虫的 **松墨天牛 Boss**。

一个基于 Canvas 的 2D 冒险小游戏，纯前端实现，无需后端。

## 剧情玩法

1. 靠近**向导**领取无人机。
2. 收集地面上的**益生菌菌落**补充能量。
3. 按住**鼠标左键**让无人机发射益生菌，净化**线虫**。
4. 净化足够多线虫后，**松墨天牛**出现，它会释放小线虫攻击你。
5. 击败天牛，松林得救！

## 功能

- **程序化松林世界**：针叶松树、草皮、岩石、洞穴随机生成
- **线虫敌人**：地表蠕动的害虫，触碰扣血
- **松墨天牛 Boss**：飞行追踪、释放小线虫、半血狂暴、顶部血条
- **无人机 + 益生菌**：飞行跟随、发射益生菌弹净化害虫
- **益生菌能量系统**：菌落可拾取，消耗制衡，需补充
- **红心生命条** + 死亡重生
- **昼夜循环**：白天、黄昏、夜晚自动流转
- **向导 NPC**：引导剧情，交付无人机

## 操作

| 按键 | 功能 |
| --- | --- |
| `A` / `D` 或 `←` / `→` | 移动 |
| `W` / `空格` / `↑` | 跳跃 |
| 鼠标左键 | 发射益生菌 |
| `H` | 隐藏/显示操作提示 |

## 本地运行

任选一种：

```bash
# Python
python -m http.server 8000
# 然后访问 http://localhost:8000
```

```bash
# Node
npx http-server .
# 然后访问 http://localhost:8000
```

> 直接双击 `index.html` 打开也可以，资源加载已兼容 `file://` 协议。

## 部署到 GitHub Pages

1. 将本仓库推送到 GitHub。
2. 打开仓库 **Settings → Pages**。
3. **Source** 选择 `Deploy from a branch`，分支选 `main`，目录选 `/ (root)`。
4. 保存后等待 1~2 分钟，访问 `https://你的用户名.github.io/仓库名/`。

> 所有资源均使用相对路径，部署在子路径也能正常工作。

## 技术栈

- 原生 HTML5 + Canvas 2D
- 确定性随机（mulberry32）+ 柏林噪声生成世界
- 纯 JS，无任何外部依赖，无需构建
