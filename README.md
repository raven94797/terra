# 泰拉瑞亚 · Web Edition

一个基于 Canvas 的泰拉瑞亚风格 2D 沙盒小游戏，纯前端实现，无需后端。

## 功能

- **程序化世界生成**：地形、树木、沙漠、洞穴随机生成
- **方块系统**：挖掘 / 放置 6 种方块，石块层含矿石点缀
- **昼夜循环**：白天、黄昏、夜晚自动流转，天空/太阳/月亮/星空随之变化
- **史莱姆敌人**：大小史莱姆 AI、跳跃追踪、受击击退、死亡分裂
- **战斗系统**：鼠标左键挥剑攻击，扇形判定，红心生命条 UI
- **凝胶收集**：击杀史莱姆掉落凝胶
- **向导 NPC**：地表游走
- **死亡重生**：生命归零后回到出生点重生

## 操作

| 按键 | 功能 |
| --- | --- |
| `A` / `D` 或 `←` / `→` | 移动 |
| `W` / `空格` / `↑` | 跳跃 |
| 鼠标左键 | 挖掘 / 挥剑攻击 |
| 鼠标右键 | 放置方块 |
| `1` - `6` / 鼠标滚轮 | 切换方块 |
| `H` | 隐藏/显示操作提示 |

## 本地运行

任选一种：

```bash
# Python
python -m http.server 8000
# 然后访问 http://localhost:8000
```

```bash
# Node
npx http-server .
# 然后访问 http://localhost:8000
```

> 直接双击 `index.html` 打开也可以，资源加载已兼容 `file://` 协议。

## 部署到 GitHub Pages

1. 将本仓库推送到 GitHub。
2. 打开仓库 **Settings → Pages**。
3. **Source** 选择 `Deploy from a branch`，分支选 `main`，目录选 `/ (root)`。
4. 保存后等待 1~2 分钟，访问 `https://你的用户名.github.io/仓库名/`。

> 所有资源均使用相对路径，部署在子路径也能正常工作。

## 技术栈

- 原生 HTML5 + Canvas 2D
- 确定性随机（mulberry32）+ 柏林噪声生成世界
- 纯 JS，无任何外部依赖，无需构建
